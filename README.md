# jpDaily

日文單字卡網頁，單一 HTML 檔，不需要建置，直接用瀏覽器開 `index.html` 就能用。

## 功能

- **今日**：新字速覽，每天 8 個。可以選「記下來」加入複習，或選「已經會了」跳過。背完還能再多學。
- **複習**：間隔重複，採用簡化版 SM-2 排程。先遮住答案，翻開後選「再一次／有點難／簡單」。
- **測驗**：每次 10 題，題型是看字選意思和看字選讀音。可以重考，也能只考錯題。
- **單字本**：看每個字的狀態，可以篩選全部、複習中或錯題。

發音使用瀏覽器內建的日語語音，進度存在瀏覽器的 localStorage。

## 鍵盤快捷鍵

| 畫面 | 按鍵 | 動作 |
| --- | --- | --- |
| 今日 | → | 記下來 |
| 今日 | ← | 已經會了 |
| 複習 | 空白鍵 | 翻開答案 |
| 複習 | 1 | 再一次 |
| 複習 | 2 | 有點難 |
| 複習 | 3 | 簡單 |

## 單字資料

目前內建 34 個 JLPT N5 單字，寫在 `index.html` 的 `W` 陣列裡。每一筆的格式如下：

```
[單字, 讀音, 中文, 詞性, 圖示, 日文例句(<b>標出單字</b>), 中文翻譯]
```

## 部署到 GitHub Pages

1. 打開 repo 的 Settings → Pages。
2. Source 選 `main` 分支，資料夾選 `/ (root)`。
3. 網址會是 `https://marekshen.github.io/jpDaily/`。
